# 画面設計

Flask で実装する初期版の画面です。投稿詳細画面は作りません。削除、いいね、ログアウトは独立した画面にせず、投稿一覧から行う操作です。各操作の URL は `docs/routes.md` に書きます。

## 画面一覧

| 画面 | 目的 | ログイン | テンプレート |
| --- | --- | --- | --- |
| 投稿一覧 | 写真を新しい順に見る。削除といいねもここから行う | 不要 | `posts/index.html` |
| ユーザー登録 | ユーザー名とパスワードでアカウントを作る | 不要 | `auth/register.html` |
| ログイン | 登録済みのユーザーとしてログインする | 不要 | `auth/login.html` |
| 投稿作成 | 写真1枚と短いキャプションを投稿する | 必要 | `posts/new.html` |

共通の見た目は `base.html` に置きます。各画面のテンプレートはこれを継承します。

## 共通ナビゲーション

全画面の上部に、次のリンクを出します。

- 常に表示: 投稿一覧
- 未ログイン: ログイン、ユーザー登録
- ログイン中: 投稿する、ログアウト

ログアウトは画面を持たず、実行後は投稿一覧へ戻します。

## 投稿一覧

トップ画面です。ログインしていなくても閲覧できます。

表示する内容:

- 写真、キャプション、投稿者、投稿日時
- 各投稿のいいね数
- 投稿が0件のときは、投稿がまだないことが分かる文言

ログイン中だけ追加する操作:

- 各投稿へのいいね、またはいいねの取り消し
- 自分の投稿だけに削除ボタン

削除もいいねも、処理が終わったら投稿一覧にとどまります。他人の投稿には削除ボタンを出しません。

## ユーザー登録

ユーザー名とパスワードを入力する画面です。

- 登録に成功したら、ログイン画面へ移動する
- 同じユーザー名が既にあるなど、登録できないときはこの画面に留まり、理由を表示する
- すでにログインしている人が開いたときは、投稿一覧へ移動する

## ログイン

ユーザー名とパスワードを入力する画面です。

- ログイン画面から自分で開いて成功したときは、投稿一覧へ移動する
- 投稿作成を開こうとして、未ログインのためこの画面へ来たときは、成功後に投稿作成へ戻す
- ユーザー名またはパスワードが違うときは、この画面に留まり、ログインできないことを表示する
- すでにログインしている人が開いたときは、投稿一覧へ移動する

## 投稿作成

ログインしたユーザーだけが開ける画面です。写真1枚とキャプションを入力します。キャプションは空でも投稿できます。

- 未ログインで開こうとしたときは、ログイン画面へ移動する。ログインに成功したら、この画面へ戻す
- 投稿に成功したら、投稿一覧へ移動する
- 写真がない、画像以外のファイルなど、投稿できないときはこの画面に留まり、理由を表示する

## 画面遷移

```text
投稿一覧
  ├─ ユーザー登録 ─成功→ ログイン ─成功→ 投稿一覧
  ├─ ログイン ─成功→ 投稿一覧
  ├─ 投稿する ─未ログイン→ ログイン ─成功→ 投稿作成 ─成功→ 投稿一覧
  ├─ 投稿する ─ログイン中→ 投稿作成 ─成功→ 投稿一覧
  ├─ いいね / いいね取り消し → 投稿一覧
  ├─ 自分の投稿を削除 → 投稿一覧
  └─ ログアウト → 投稿一覧
```

今回作らない画面は、投稿詳細、コメント、検索、フォロー、キャプション編集です。
