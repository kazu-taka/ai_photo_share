# 実装タスク

上から順に作ります。各タスクは、完了条件を満たしてから次へ進みます。規則は `docs/coding_rules.md`、全体像は `docs/ai_context.md` です。

## 必須

### 1. 起動と共通画面

- `app.py` で Flask を起動し、`.env` の `SECRET_KEY` を読む
- セッションの保存先を `instance/sessions/` にする
- `base.html` に、ログイン状態で切り替わるナビゲーションを置く
- `static/css/` に、一覧とフォームが読める最小限の CSS を置く

完了条件: `http://127.0.0.1:5000/` を開くと、未ログイン用のナビゲーションが出る。

### 2. モデル

- `models.py` に `users`、`posts`、`likes` を作る
- SQLite は `instance/app.db` とし、接続のたびに外部キーを有効にする
- 起動時に、テーブルがなければ作る

完了条件: 起動後に3つのテーブルがあり、`users.username` と `users.email` は大文字小文字を区別せず一意である。

### 3. ユーザー登録

- `GET, POST /register` を作る
- ユーザー名、メールアドレス、パスワードを検証し、パスワードはハッシュ化して保存する
- 成功したら `/login` へ移る。重複などの失敗時は登録画面に理由を出す
- ログイン済みで開いたときは `/` へ移る

完了条件: 新規登録できる。同じユーザー名、または同じメールアドレスでは登録できない。データベースに平文のパスワードがない。

### 4. ログインとログアウト

- `GET, POST /login` と `POST /logout` を作る
- ログイン成功時は `/` へ移る。`next` が `/posts/new` のときだけ `/posts/new` へ移る
- ユーザー名またはパスワードが違うときは、ログイン画面に留まり、ログインできないと表示する
- ログアウト後は `/` へ移る。未ログインでログアウトしても `/` へ移る

完了条件: 登録したユーザー名とパスワードでログインでき、ログアウトすると未ログインのナビゲーションに戻る。

### 5. 投稿一覧

- `GET /` で投稿を新しい順に出す
- 各投稿に、写真、キャプション、投稿者、投稿日時、いいね数を出す
- 投稿が0件のときは、投稿がまだないことが分かる文言を出す
- この時点では、削除ボタンといいねボタンはまだ出さなくてよい

完了条件: 未ログインで一覧を開ける。投稿が0件の表示が分かる。

### 6. 投稿作成と写真の表示

- `GET, POST /posts/new` を作る。未ログインは `/login?next=/posts/new` へ移す
- 写真1枚はプロジェクト直下の `uploads/` に保存する。データベースには保存時のファイル名だけを書く
- `GET /uploads/<filename>` で、そのフォルダの画像を返す
- `.gitignore` に `uploads/` を追加する
- 成功したら `/` へ移る。失敗時は投稿画面に理由を出す

完了条件: ログインしたユーザーが写真を1枚投稿でき、一覧にその写真が表示される。`uploads/` が Git の管理対象外である。

### 7. 自分の投稿の削除

- `POST /posts/<int:post_id>/delete` を作る
- ログイン中かつ投稿者本人のときだけ削除する
- 投稿行、その投稿のいいね、`uploads/` 内の画像ファイルを削除する
- 一覧では、自分の投稿にだけ削除ボタンを出す
- 未ログインは `/login` へ移す。他人の投稿や存在しない投稿は削除せず `/` へ戻す

完了条件: 自分の投稿は一覧から消え、画像ファイルも `uploads/` から消える。他人の投稿は削除できない。

### 8. いいね

- `POST /posts/<int:post_id>/like` を作る
- ログイン中のユーザーが、その投稿にいいねしていなければ追加し、していれば取り消す
- 一覧にはいいね数と、ログイン中だけいいねボタンを出す
- 未ログインは `/login` へ移す。存在しない投稿は何も変更せず `/` へ戻す

完了条件: 同じ投稿へいいねできるのは1人1回までで、もう一度押すと取り消され、件数が変わる。
