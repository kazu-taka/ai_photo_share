# 写真共有アプリ 要件定義

Flask と Peewee で作る、インスタグラム風の小さな写真共有アプリの要件です。まずは自分の PC 上で動かす学習用の初期版とします。

## アプリの概要

友人同士が、旅行や日常の写真を1枚ずつ見せ合うアプリです。

- 投稿は「写真1枚」と「短いキャプション」で構成する
- 投稿一覧は、ログインしていなくても誰でも見られる
- ユーザー登録とログインは、投稿する人に必要
- ログインした人は、投稿への「いいね」と、自分の投稿の削除ができる
- 写真ファイルは、外部サービスではなくアプリ内のフォルダに保存する
- コメント、検索、フォローは今回の対象外

## 想定ユーザー

旅行や日常の写真を、少人数の友人と見せ合う人です。

- 見る人: アカウントがなくても投稿一覧を閲覧できる
- 投稿する人: ユーザー登録とログインをして、写真を投稿する
- 利用者数や同時アクセスは、自分の PC で試す規模を想定する

## 必須機能

初学者が順に実装できるよう、機能を小さく分けています。上から順に作ると、前の機能を次の機能で使えます。

### 1. ユーザー登録

- ユーザー名とパスワードでアカウントを作れる
- 同じユーザー名は登録できない
- パスワードは平文で保存しない

### 2. ログイン

- 登録済みのユーザー名とパスワードでログインできる
- ユーザー名またはパスワードが違うときは、ログインできない

### 3. ログアウト

- ログイン中のユーザーがログアウトできる

### 4. 投稿一覧

- 投稿を新しい順に一覧表示する
- 各投稿には、写真、キャプション、投稿者、投稿日時を表示する
- ログインしていなくても閲覧できる
- 投稿が0件のときは、その旨が分かる表示にする

### 5. 投稿作成

- ログインしたユーザーだけが投稿できる
- 1回の投稿でアップロードできる写真は1枚
- キャプションは短文とする（空でも投稿できる）
- 未ログインの人が投稿しようとしたら、ログインを求める

### 6. 自分の投稿の削除

- ログインしたユーザーは、自分の投稿だけ削除できる
- 削除すると、一覧からその投稿が消える
- 他人の投稿は削除できない

## 余裕があれば追加する機能

初期版が動いてから検討します。今回は実装しません。

- コメント: ログインしたユーザーが、投稿に短いコメントを残せる

検索とフォローは、今回の検討対象にしません。

## 非機能要件

- 実行環境は、まずは自分の PC とする。公開やデプロイは対象外
- Web フレームワークは Flask、データベースアクセスは Peewee を使う
- データベースは、学習用として SQLite でよい
- 写真ファイルはアプリ内のフォルダに保存する
- 画面は、投稿・一覧・ログインに必要な最小限の見た目でよい
- 想定する利用は少人数であり、性能や大規模な同時アクセスは求めない

## 実装時に注意すべきこと

- パスワードはハッシュ化して保存する。データベースに平文を書かない
- 投稿、削除、いいねは、ログインしていることを確認してから処理する
- 削除は投稿者本人だけに許可する。投稿 ID を知っていても他人の投稿は消せないようにする
- アップロードを許可する拡張子を、画像（例: jpg, jpeg, png, gif）に限る
- 保存するファイル名は、利用者が送った名前をそのまま使わない
- キャプションの文字数に上限を設ける
- 写真の保存先フォルダとデータベースファイルは、Git の管理対象から外す
- コメント、検索、フォロー、キャプション編集、外部ストレージへの保存は、この初期版では作らない
