# ルーティング設計

Flask のルート定義に対応する一覧です。画面の目的と遷移の考え方は `docs/screens.md` に書きます。

状態を変える処理は POST にします。成功した POST は、同じ内容の再送信を防ぐため、画面を再表示せず別の URL へリダイレクトします。入力エラーのときは、同じ画面のテンプレートを再表示します。

## ルート一覧

| 処理 | メソッド | URL | ログイン | テンプレート | 成功時の移動先 |
| --- | --- | --- | --- | --- | --- |
| 投稿一覧 | GET | `/` | 不要 | `posts/index.html` | なし |
| ユーザー登録の表示 | GET | `/register` | 不要 | `auth/register.html` | なし |
| ユーザー登録の実行 | POST | `/register` | 不要 | 失敗時は `auth/register.html` | `/login` |
| ログインの表示 | GET | `/login` | 不要 | `auth/login.html` | なし |
| ログインの実行 | POST | `/login` | 不要 | 失敗時は `auth/login.html` | `/` または `/posts/new` |
| ログアウト | POST | `/logout` | 必要 | なし | `/` |
| 投稿作成の表示 | GET | `/posts/new` | 必要 | `posts/new.html` | なし |
| 投稿作成の実行 | POST | `/posts/new` | 必要 | 失敗時は `posts/new.html` | `/` |
| 投稿の削除 | POST | `/posts/<int:post_id>/delete` | 必要 | なし | `/` |
| いいねの切り替え | POST | `/posts/<int:post_id>/like` | 必要 | なし | `/` |
| 写真の表示 | GET | `/uploads/<filename>` | 不要 | なし | なし |

`<int:post_id>` は投稿の数値 ID です。写真の表示は画面ではなく、投稿一覧の画像が参照するファイル配信用のルートです。

Flask のエンドポイント名は次のとおりにします。

| 処理 | エンドポイント名 |
| --- | --- |
| 投稿一覧 | `index` |
| ユーザー登録 | `register` |
| ログイン | `login` |
| ログアウト | `logout` |
| 投稿作成 | `post_new` |
| 投稿の削除 | `post_delete` |
| いいねの切り替え | `post_like` |
| 写真の表示 | `uploaded_file` |

## 各ルートの動き

### 投稿一覧 `GET /`

投稿を新しい順に表示します。ログインの有無で、出すボタンが変わります。

- 未ログイン: 閲覧といいね数の表示だけ
- ログイン中: いいねボタンを出す。自分の投稿には削除ボタンも出す

### ユーザー登録 `GET /register`、`POST /register`

- GET は入力画面を表示する
- POST はユーザーを作成し、成功したら `GET /login` へリダイレクトする
- ユーザー名の重複などで失敗したときは、`auth/register.html` を再表示する
- ログイン済みで開いたときは、`GET /` へリダイレクトする

### ログイン `GET /login`、`POST /login`

- GET は入力画面を表示する
- POST は認証し、失敗したときは `auth/login.html` を再表示する
- 成功時の移動先は、クエリ `next` が `/posts/new` のときだけ `GET /posts/new` とする。それ以外は `GET /` とする
- ログイン済みで開いたときは、`GET /` へリダイレクトする

`next` に許可するのは `/posts/new` だけです。任意の URL へ戻すと、ログイン後に意図しないページへ移動できます。

### ログアウト `POST /logout`

ログイン状態を消し、`GET /` へリダイレクトします。未ログインで呼ばれたときも、投稿一覧へ戻します。GET では受け付けません。

### 投稿作成 `GET /posts/new`、`POST /posts/new`

ログインが必要です。未ログインのときは `GET /login?next=/posts/new` へリダイレクトします。

- GET は投稿フォームを表示する
- POST は写真1枚とキャプションを受け取り、成功したら `GET /` へリダイレクトする
- 写真がない、許可していない拡張子などのときは、`posts/new.html` を再表示する

### 投稿の削除 `POST /posts/<int:post_id>/delete`

ログインが必要です。投稿者本人の投稿だけ削除し、`GET /` へリダイレクトします。

- 未ログインのときは `GET /login` へリダイレクトする
- 他人の投稿、または存在しない投稿のときは削除せず、`GET /` へ戻す

GET では受け付けません。リンクを開いただけで削除されないようにするためです。

### いいねの切り替え `POST /posts/<int:post_id>/like`

ログインが必要です。そのユーザーがその投稿にいいねしていなければ追加し、していれば取り消します。処理後は `GET /` へリダイレクトします。

- 未ログインのときは `GET /login` へリダイレクトする
- 存在しない投稿のときは何も変更せず、`GET /` へ戻す

1人のユーザーが同じ投稿へいいねできるのは1回までです。GET では受け付けません。

### 写真の表示 `GET /uploads/<filename>`

アプリ内のアップロードフォルダから、指定された画像ファイルを返します。テンプレートは使いません。

ファイル名は、保存時に付けた名前だけを受け付けます。利用者が送った元のファイル名や、フォルダを遡る文字列は使いません。
